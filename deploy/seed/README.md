# Описания категорий и подкатегорий (SEO-тексты)

`category-descriptions.json` — тексты для поля **«Описание»** категорий и подкатегорий
(показываются блоком внизу страницы раздела). Ключ = точное название раздела, значение =
готовый HTML. Сгенерированы из экспорта Satu.kz (лист «Export Groups Sheet», колонки
«Описание группы до/после списка товаров»).

## Применить на сервере

```bash
cd ~/sigma-shop
node scripts/import-descriptions.js      # заполнит только ПУСТЫЕ описания
sudo pm2 restart sigma-shop
```

- по умолчанию не трогает то, что уже заполнено (ручные правки в админке в безопасности);
- `node scripts/import-descriptions.js --force` — перезаписать все совпадения по названию.

## Пересобрать из свежего экспорта

```bash
python3 scripts/build-descriptions.py ~/Downloads/export-products-XX.xlsx
```
Перезапишет `category-descriptions.json`. Нужен экспорт Satu **с группами**
(Товары + Группы), иначе описаний в файле не будет.

Дальше тексты правятся в админке: **Категории / Подкатегории → «Описание»**
(есть кнопки форматирования и режим «</> HTML»).
