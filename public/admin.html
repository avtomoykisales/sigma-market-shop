Дополнительно

Контактные номера

Кнопки «WhatsApp» и «Позвонить» на карточках товаров. Формат любой — +7 (707) 420-20-03 или 87074202003.

CRM — Bitrix24

Заявки с сайта («Получить консультацию» и корзина) будут падать в Bitrix24 как лиды.
В Bitrix24: Приложения → Разработчикам → Другое → Входящий вебхук, права crm, скопировать адрес вида https://ваш-портал.bitrix24.kz/rest/1/xxxxxxxx/ и вставить сюда. Пусто — интеграция выключена.

Квиз-подбор оборудования

Каждый вариант ответа: category — slug категории; perfMin/perfMax — диапазон производительности; priceMin/priceMax — бюджет, ₸. По ответам сайт подбирает 2–3 товара.

🖼 Загрузка изображений товаров

Массовая загрузка ZIP-архива с картинками (PNG/JPG). Затем в карточке товара нажмите «Загрузить» или добавьте файл по имени. Для одного товара удобнее загружать изображения прямо в его карточке.

Загрузить одну иконку

Загрузите иконку для конкретного товара. Имя файла укажите в поле «Иконка» в карточке товара.
